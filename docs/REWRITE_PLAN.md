# Итог переноса монолита

Перенос выполнен по слоям с сохранением рабочих промежуточных сборок.

1. Каркас workspace, NestJS, React, MAX auth, health и session — выполнено.
2. SQLite schema/repositories и совместимые runtime-миграции — выполнено.
3. Пользователи, регистрация, роли и профиль — выполнено.
4. Ученик: домашние задания, файлы, исправления, рейтинг и обратная связь — выполнено.
5. Преподаватель: очередь проверки, ученики, оценки, комментарии и чат — выполнено.
6. Администратор: модерация, назначения, профили и аудит — выполнено.
7. Гость и безопасное публичное портфолио — выполнено.
8. React-страницы, формы, загрузки, темы, адаптивность и MAX Bridge — выполнено.
9. Деморежим для проверки экспертами — выполнено.
10. Docker, production-конфигурация и автоматический API smoke — выполнено.

Активными являются только workspace `frontend/` и `backend/`. Исторические корневые файлы не входят в npm scripts и Docker runtime. Подтверждение готовности находится в `PRODUCT_AUDIT.md`; публикация в `main`, push и deployment выполняются отдельно после разрешения.
