# Сверка функциональности с версией от 15.09.2026

Источник: архив `Дневник_Академии_для_программиста_2026_09_15.zip`.

## Осознанно не переносим

- Telegram-, VK- и web-login: целевой продукт работает только в MAX.
- Связку Telegram ID и VK ID: в новом продукте идентификатором пользователя будет MAX ID.

## Уже перенесено

- роли ученика, преподавателя, администратора и гостя;
- MAX init-data authentication и локальный demo-режим;
- публичное портфолио;
- чтение учебных работ, статусы, комментарии и отзывы;
- проверка работы преподавателем;
- базовая админская сводка;
- API чата, уведомлений, регистрации, профиля, заявок и доработки работы.

## Требует переноса в интерфейс или расширения API

### Ученик

- регистрация и редактирование профиля;
- создание, редактирование и повторная отправка ДЗ;
- вложения и безопасная выдача файлов;
- детальная карточка работы с историей комментариев;
- уведомления, чат с преподавателем, приватная обратная связь.

### Преподаватель

- профиль преподавателя;
- отдельная очередь работ и карточка ученика;
- поиск учеников по имени/фамилии;
- чат с учеником;
- просмотр статистики ученика и портфолио.

### Администратор

- поиск и фильтры учеников по имени и учебной категории;
- карточки учеников и преподавателей;
- создание/изменение учеников;
- назначение и снятие преподавателей;
- обработка заявок преподавателей и изменений профиля;
- просмотр обратной связи, журнала действий и уведомлений.

### Гость

- отдельная карточка публичного ученика с полной витриной работ и оценками.

## Шкала оценки

Последняя версия использует шкалу **1–5**, а не 1–10: интерфейс показывает пять звёзд и `/5`, а схема БД ограничивает `rating` диапазоном `1..5`. Новая версия сохраняет это поведение.
