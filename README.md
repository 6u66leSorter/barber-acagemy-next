# MADCAP Barber Academy

MAX Mini App для учеников, преподавателей, администраторов и гостей.

Новая архитектура находится в `backend/` и `frontend/`: NestJS + TypeScript на
сервере, React + TypeScript + Vite в клиенте. План переноса функционала описан в
[`docs/REWRITE_PLAN.md`](docs/REWRITE_PLAN.md), устройство слоёв — в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Возможности

- регистрация и управление ролями;
- домашние задания, проверки, оценки, вложения и комментарии;
- API и структурированный shell кабинетов ученика, преподавателя и администратора (перенос экранов продолжается по плану);
- профили и публичное портфолио без контактных данных;
- конфиденциальная обратная связь ученика администратору;
- светлая и тёмная темы;
- локальный деморежим для просмотра всех ролей.

## Локальный запуск новой версии

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

API работает на `http://localhost:8787`, клиент — на `http://localhost:5173`.
Создайте `backend/.env` на основе `backend/.env.example`. Для локального
интерфейса без MAX init data разрешён только development-режим.

## MAX Mini App

Скопируйте `backend/.env.example` в `backend/.env`, задайте `MAX_BOT_TOKEN` и
не коммитьте этот файл. Проверка токена выполняется отдельной server-side
командой после переноса CLI.

```bash
npm run max:check-token
```

Для запуска на телефоне production-сборка frontend должна быть опубликована по
HTTPS, а `/api` — проксирован на Nest API.

Затем опубликуйте порт `4173` через HTTPS-туннель и укажите полученный адрес в
настройках MAX-бота. Клиентские данные MAX проверяются API по подписи и сроку
жизни.

## Проверка

```bash
npm run lint
npm run build
```

Автоматический деплой отключён. Старый сервер и домен не используются. Старый
монолитный код сохраняется в исходной ветке до завершения переноса и удаления
после отдельной проверки.
