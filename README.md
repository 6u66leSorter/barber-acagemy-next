# MADCAP Barber Academy

MAX Mini App для учеников, преподавателей, администраторов и гостей. MAX —
единственная поддерживаемая платформа входа. Для разработки сохранён локальный
браузерный режим, а публичное портфолио доступно без авторизации.

## Возможности

- регистрация и управление ролями;
- домашние задания, проверки, оценки, вложения и комментарии;
- кабинеты ученика, преподавателя и администратора;
- профили и публичное портфолио без контактных данных;
- конфиденциальная обратная связь ученика администратору;
- светлая и тёмная темы;
- локальный деморежим для просмотра всех ролей.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
```

В первом терминале запустите API с отключённой MAX-авторизацией:

```bash
npm run api:local
```

Команда создаёт локальную SQLite-базу `data/barber.db`, поэтому используйте её
только для разработки. Во втором терминале запустите frontend:

```bash
npm run dev:local
```

Откройте `http://localhost:5173`. Для демонстрации ролей можно открыть
`http://localhost:5173/?preview=demo`, а для публичного портфолио —
`http://localhost:5173/?guest=1`.

## MAX Mini App

Скопируйте `.env.example` в локальный `.env`, задайте `MAX_BOT_TOKEN` и не
коммитьте этот файл. Проверка токена:

```bash
npm run max:check-token
```

Для запуска на телефоне:

```bash
npm run api:max
npm run build
npm run preview:max
```

Затем опубликуйте порт `4173` через HTTPS-туннель и укажите полученный адрес в
настройках MAX-бота. Клиентские данные MAX проверяются API по подписи и сроку
жизни.

## Проверка

```bash
npm run lint
npm run build
```

Автоматический деплой отключён. Старый сервер и домен не используются.
