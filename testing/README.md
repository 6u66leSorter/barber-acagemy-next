# Проверки проекта

## API smoke

`api-smoke.mjs` работает только с временными данными: создаёт отдельные SQLite и uploads в системном temp-каталоге, запускает собранный Nest API на свободном localhost-порту и удаляет каталог после завершения.

```bash
npm run build -w backend
node testing/api-smoke.mjs
```

Проверяются:

- повторный идемпотентный запуск demo seed;
- гостевая приватность;
- сессии ученика, преподавателя и администратора;
- отсутствие персональных MAX-полей в teacher/chat ответах;
- запрет admin API для ученика;
- внутренние `users.id` в чате и сообщения в обе стороны;
- запрет чтения чужого диалога;
- загрузка настоящего PNG, создание и проверка работы;
- недоступность pending-файла гостю и доступность после одобрения;
- запрет самостоятельной регистрации, подтверждение подписанного номера, гостевой режим неизвестного номера и активация ученика по назначению;
- правка профиля и приватная обратная связь;
- запрет старой заявки преподавателя и активация преподавателя по назначенному номеру;

Тест требует предварительно собранный `backend/dist` и установленные зависимости backend workspace. Он не использует и не изменяет `data/barber.db`.

## Модульные тесты

```bash
npm test
```

Набор должен проверять MAX init data, разграничение доступа к чатам, выключение чата через окружение, срок хранения уведомлений, сигнатуры файлов, непрозрачные имена и владение `file_id`.
